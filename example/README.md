# Example Team Repository

A minimal example of a staghorn source repo. Each file shows the structure and format — not production-quality content.

```
team-repo/
├── .staghorn/
│   └── source.yaml          # Marks this as a source repo
├── CLAUDE.md                # Shared guidelines
├── commands/
│   └── code-review.md       # Example command
├── evals/
│   └── team-security.yaml   # Example eval
├── languages/
│   └── python.md            # Example language config
├── rules/
│   └── security.md          # Example rule (global scope)
└── templates/
    └── backend-service.md   # Example project template
```

For a full production example, see [HartBrook/staghorn-community](https://github.com/HartBrook/staghorn-community).
